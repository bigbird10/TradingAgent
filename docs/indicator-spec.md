# TradingAgent 指标规范与黄金样例

TA-07 · 已确认规范 `indicator-spec-1.0.0` · 2026-11-10。本文固定 TA-07 评审通过的计算与证据规则。范围和约束见 [需求规格](requirements.md)、[架构决策 Q-02 至 Q-06](architecture.md#10-决策记录与阶段交接) 及 [TA-01 实测](validation/akshare-feasibility.md) 为准。

## 1. 适用范围与共同契约

已确认的范围包括基本面、估值、MA20、MA60、EMA(12,26,9) MACD、RSI14，以及量价、波动与流动性输入。技术默认采用前复权的已完成日线。财务输入依据正式披露，并区分报告期、披露日、更新日、TTM 与静态口径。本文只定义计算和可用性条件，风险等级、阈值、评分聚合和行业策略由 TA-10/11 单独处理。

- **数据身份**。每组输入固定交易所、六位代码、上海分析基准时点、同一币种、单位和口径。按数据类别校验时间与覆盖。缓存 TTL 不改变原始获取时间或业务时效。风险警示和停牌需状态证据，缺失交易记录只说明数据缺口。
- **结果证据**。建议每项结果保留稳定指标 ID、值或空、规范单位、状态及原因、观察时点或期间、样本窗口及实际样本数、来源引用、输入证据 ID、计算方式和 `indicator_spec_version`。供应商直接值单列为来源值并保留原字段和原口径。
- **状态语义**。正常结果含明确值，已观测的零仍为有效数据。缺字段、尚未披露、披露证据不足、样本不足、不可适用、无效数据及冲突分别记录，输出空值而非默认零。计算仅使用同口径且在基准时点已可用的输入。风险和评分模块另做资格判断。
- **复算边界**。冻结分析时点的输入与版本。业务上只对经确认的规则和源映射启用正式计算。规格变更、新披露和复权修订应保留原快照，重新分析生成新结果。
- **精度边界**。金额和倍数保留精确十进制或参考样例声明的容差，展示舍入独立进行。校验先检查状态、单位和期间，再比较数值。按指标处理误差，禁止用统一的大容差掩盖口径差异。

现有 `DatasetRequest.as_of`、`Observation.observed_on/available_at`、`FieldEvidence` 和 SQLite 快照可承载这些记录。财报适配器应先按证据筛选时点可用版本，再提交同证券同报告期的一条有效观察值，符合现有标准化契约。TA-07 的实现交付是独立参考计算与黄金断言。TA-08、TA-09 按本规范接入生产指标、数据适配及快照。

## 2. 财务指标与估值（AT-04、AT-05）

### 财报取数与时点

- 按证券、财报范围、会计期间、币种和修订版本对齐。资产负债表是期末存量，利润表和现金流量表默认是同一会计年度年初至报告期末累计流量。报告期末、实际披露时间、供应商更新与本地获取时间分别记录。
- 使用合并报表。正式报告和更正公告各自作为证据，须证明某一数值确属该版本。若正式披露带有可信且时区明确的时间戳，以 Asia/Shanghai 转换后的时间作为可用边界，边界含等号。仅有可核实公告日期时，使用证券所属市场日历，取严格晚于公告日期的下一交易日上海时间 00:00。周末及休市日顺延，交易日历无法覆盖公告次日至候选交易日的连续区间时，标记可用时点缺少证据。这是首版保守策略，与实际日内发布时间无关。预约日期、报告期末、供应商原披露字段和更新时间均不能独立证明当前行的版本。
- 在基准时点选择最新且有证据可用的版本。未来更正存在时仍可用已核实的旧版。若当前接口只返回更正值且旧版不可重建，较早基准时点标记为缺失，并保留原因。相同可用时点的版本冲突未经裁决时标记为数据不可用。不得混用未来行或把供应商更新时间解释为更正首次披露时间。
- 五洲交通 2024 年营业收入更正公告记录更正前 1,823,013,143.58 元及更正后 1,562,610,519.04 元。TA-01 的东财回包把后者与较早的原披露日放在一起。旧分析只有在能核实旧版时才可取得前者。 [实测记录](validation/akshare-feasibility.md) · [公司更正公告](https://static.cninfo.com.cn/finalpage/2025-12-20/1224888631.PDF)

每次分析必须保存分析时点、行情时点、财报报告期、首次披露时间及精度、所用财报版本及其修订时间、来源、规则版本和可用时间的推导依据。区分公告原始时间与保守生效时点。披露、修订或历史股本证据不足时，可保留另有证据支持的当前观察或来源值，并列明缺口。此类结果不能标注为严格 PIT 历史估值，也不能用于回填历史评分。

### 基本面计算

金额输入先按来源证据转换为人民币元，输出保留金额或比例语义。比例在计算时保留原值，界面按百分比呈现。负现金流或当期净亏损是有效事实。无字段、未披露、币种不兼容、比较基期不适用均须附原因。

| 指标 | 公式及输入范围 |
| --- | --- |
| 营收、净利润、经营活动现金流 | 最新可用报告期的合并营业收入、合并净利润、经营活动现金流量净额，保留累计期间。归母净利润同时独立展示。 |
| 毛利率 | `(营业收入 − 营业成本) / 营业收入`，同一合并报表、期间和成本范围，分母必须为正。 |
| 净利率 | `合并净利润 / 营业收入`，分母必须为正。合并净利润为负时保留负比例。 |
| ROE | `归母净利润 / [(期初归母权益 + 期末归母权益) / 2]`。期初取上年末，期末取目标报告期末，两端均须为正。报告期 ROE 保留报告期起止与累计口径，比例乘 100 后按百分比显示。上半年或前三季累计 ROE 与完整年度 ROE 分开。单季、年化和 TTM ROE 需另设口径标识，首版默认计算未年化的报告期 ROE，不跨不同期间直接比较。任一端权益为零或负数时标不适用，缺期初或期末权益标缺失，不以期末权益代替均值。供应商加权平均 ROE 可在验证口径后单列。 |
| 营收、归母净利润同比 | 营收取合并营业收入，利润取归母净利润。均按 `(本期累计 − 上年同期间累计) / 上年同期间累计` 计算，以同币种、合并范围、计量基础为前提，分母须为正。上期为零、亏损、扭亏或连续亏损时报告原值及方向，增长率标不适用；正基期转亏可产生小于 −100% 的可计算比例。 |
| 资产负债率 | `期末总负债 / 期末总资产`，同一合并资产负债表，总资产须为正。真实比率超过 100% 时保留，不设上限。 |
| 财务趋势 | 并列最近三个已披露年度与最新累计期间的同比，不把累计值当单季。同比基期的更正也须通过同一分析时点校验。 |

### 估值计算

估值基准取最近可验证的已完成交易日收盘时点，且行情须在分析时点已可取得。财务分母的可用时间必须不晚于对应收盘时点。盘后披露可进入当晚基本面分析，在下一满足条件的行情时点才可进入估值。市值使用该行情时点的未复权价格和已生效且当时可证明的适用股本。股本有效区间左闭右开，不能用当前股本回算过去市值。可直接使用已证明与该价格、股本、发行人、权益范围、币种及市场定价口径一致的市值。分母的币种、发行人与权益范围须匹配。交叉上市、复权或股本变更使一致性无法证明时，可另列有证据的来源值，停止本地合成。

- TTM 流量为连续四个不重叠单季值之和，单季可以由同一会计年度相邻累计数相减。对于最新 Q1–Q3，可等价使用 `上年完整财年 + 本年累计 − 上年同期间累计`，若两个路径都可验证，应比较其覆盖和结果。一致前提包含期间、会计范围、币种及更正口径。四个季度覆盖不足且桥接数据不齐，或两种结果超出已核准的来源精度，输出缺失或冲突。最新正式年度可直接用完整年度作为该年度期末 TTM。
- PE TTM 为 `总市值 / 归母净利润 TTM`；PE 静态为 `总市值 / 最新已正式披露完整财年归母净利润`。分母须为正，亏损或零利润标不适用并保留原值。分母为正且当前转亏导致 TTM 仍为正时，不将静态与 TTM 混用。
- PB 为 `总市值 / 最新合并期末归母权益`；PS TTM 为 `总市值 / 营业收入 TTM`。分子、分母均须为正。负权益和零收入有独立不可计算原因。
- EV/EBITDA 是条件指标。EV 为同日股权市值加同口径带息债务、优先权益和少数股东权益，减现金及现金等价物；EBITDA 由可核验的 TTM EBIT 加折旧和摊销得到。需验证净债务、权益范围、EBIT 与折旧摊销的同口径关系，无法取得完整依据时输出缺失，禁止用默认值或凭标签直接拼接。金融行业或 EBITDA 非正时标不适用。
- 普通企业公式适用性逐项检查。金融股可保留有明确口径的可用基础数据和部分分析。缺少经验证的专用策略时保持综合分缺失，评分适用清单和门槛交 TA-10。
- 计算采用十进制或同等精度的确定性计算。货币、百分比及倍数默认展示两位小数，展示舍入与中间值分离。黄金样例的分数结果按精确有理数对比，不以显示舍入替代判定。本规范未定义投资评价阈值。

### 独立黄金依据

财务 Fixture 以人民币元为金额单位，比例以无量纲小数表示，估值为倍数。例中 `(100−65)/100=35%`、`8/[(80+120)/2]=8%`、`120/200=60%`。归母净利润从 4 增至 8，归母同比为 100%。合并净利润从 8 增至 10，对应 25%，本期合并净利率为 10%。TTM 的两条路径分别是 `100+100+150+150=500` 和 `450+150−100=500`。以 1,000 元总市值分别除以 50 元 TTM 归母利润、250 元归母权益和 500 元 TTM 营收，得到 20、4 和 2 倍。财报更正样例冻结公告证据与两个版本的数值。盘后披露样例分别断言收盘估值和当晚分析采用的版本。

## 3. 技术指标与量价输入（Q-02）

### 输入与样本

- 按交易所、证券代码、Asia/Shanghai 交易日和同一前复权口径冻结快照。默认请求最近最多 250 根已完成的有效日线。所需有效样本超过默认窗口或初次取数不足时，可按需扩大请求。不得跨未解释的缺口拼接样本。保存实际请求窗口、冻结输入的起止日、数据截止日、来源、复权和有效根数。计算不截断为 250 根，各平滑序列从实际冻结窗口第一根起算。对比快照时说明输入窗口或源数据修订的差异。
- 只纳入有证据表明在 `as_of` 前已经完成且可用的日线。初版适配器仍保守截至上海前一自然日。启用当日收盘数据前须有完成及可用证据。拒绝混合证券、复权口径、非有限价格和未经解决的重复日线，区分来源冲突和数据缺失。
- 休市和已证实的停牌不造价量记录，不计为样本，也不打断两侧真实观测。波动率中的跨停牌收益代表相邻两个可观测收盘之间的变动。交易日状态未知而缺 bar、交易日发生异常缺口或缺收盘时，以最近一个缺口后的有效连续后缀重新预热，并记录缺口。样本不足由缺口导致时返回 `missing_data`，正常上市历史不足时返回 `insufficient_history`。日历证据不足时记录交易日状态未知，不能从空响应推断停牌。
- 收盘价采用元/股，成交量使用标准化的股，成交额为人民币元。均值与量比使用观测到的成交量及成交额，不随前复权乘价格因子。可用的价格指标与缺失量额指标可各自输出。已知的零成交量和空值分别处理。前复权非正值可保留用于价位与差分运算，但波动率窗口包含非正价时返回 `invalid_data`，不使用绝对值或其他复权方式替代。

### 公式与边界

| 指标 | 计算口径 | 最少样本与输出单位 |
| --- | --- | --- |
| MA20、MA60 | 当前及此前最后 N 个有效收盘的算术平均。趋势描述如 `MA20 - MA60` 的符号可追溯到数值，不引入评级阈值。 | 分别 20、60 根，元/股 |
| MACD | `EMA_N` 首值取前 N 个有效样本的 SMA，后续为 `α × 当前值 + (1 - α) × 前一 EMA`，`α = 2/(N+1)`。EMA 在首个有效值前不可计算。分别从同一窗口第一根计算 EMA12 和 EMA26，`DIF = EMA12 - EMA26`，`DEA = EMA9(DIF)`，首个 DEA 取前 9 个有效 DIF 的 SMA，`histogram = 2 × (DIF - DEA)`。 | DIF 第 26 根可用，DEA 和柱第 34 根可用，元/股 |
| RSI14 | 14 个相邻收盘变化分解为 `gain = max(Δ, 0)`、`loss = max(-Δ, 0)`。以首 14 个变化的平均初始化，后续使用 Wilder 平滑 `(13 × 前均值 + 本次变化分量)/14`。输出 `100 × 平均涨幅/(平均涨幅 + 平均跌幅)`。双零时取 50，仅有上涨取 100，仅有下跌取 0。 | 15 根，0～100 点 |
| 年化实现波动率 | 最近 N+1 个有效收盘产生 N 个简单收益（N 默认 20，可配置，至少为 2） `rᵢ = closeᵢ/closeᵢ₋₁ - 1`，对收益用样本标准差（分母 `N-1`），乘 `√252`，记录实际生效窗口和年化系数。 | N+1 根，默认 21 根，无量纲小数，展示百分比 |
| 日均量、均额 | 分别使用最近 L 个有效收盘观测的实际成交量和成交额（L 默认 20，可配置，至少为 1）。缺失字段不跨窗口补齐，负数和非有限量额标为 `invalid_data`。 | L 根，默认 20 根，股、元 |
| 成交量相对水平 | 最新量除以前 L 根的平均量，分母排除当期，沿用均量的缺失与无效输入校验。分母为零返回 `invalid_denominator`，缺失量返回 `missing_data`。与均额一起提供可追溯的流动性输入，等级及阈值留待 TA-10。 | L+1 根，默认 21 根，倍数 |

计算内层不按展示位数舍入。采用十进制至少 34 位工作精度或通过同等精度验证的计算，最终展示采用半偶舍入，价格线及均量额展示 2 位，RSI 展示 2 位，波动率百分比和量比展示 2 位。评测使用未展示数值，合成样例绝对容差为 `1e-10`。黄金样例冻结单位元数据，并精确比较所声明的缺失状态和有效根数。实际交易日及其来源证据由 TA-09 验证。实现应保留公式版本、参数、证据引用和输出状态，不将未计算值填为零。可用性和异常状态采用本规范共通状态，技术样例另区分 `insufficient_history` 与 `invalid_denominator`。

Wilder 平滑可参考 TA-Lib 的公开定义。以上 EMA 的独立窗口起点、MACD 柱系数和价格异常处理由本规范单独约定。 [TA-Lib RSI 定义](https://ta-lib.org/functions/rsi.html)

### 独立黄金依据

线性收盘 1～60 的均线由等差数列首尾平均得到，稳定的快慢 EMA 差为 7。第 35 根叠加 10 的单点冲击后，DIF 增量由 `10 × (2/13 - 2/27)` 求得，DEA 增量为该值的 1/5。交替涨 10%、跌 10% 的 20 个收益均值为零，年化样本波动率为 `0.1 × √(5040/19)`。混合方向的 RSI 例以首 14 次变化的均值 1 和 0.5 加一次上涨 2 得到 `3000/43`。pytest 使用独立的闭式权重和样本标准差核对期望。首个 DEA 边界样例的前 8 个 DIF 为 7，第 9 个为 `7+b`，其中 `b=10 × (2/13 − 2/27)`，故首个 DEA 为 `7+b/9`。扩窗样例使用 251 根，按 250 个收益计算平盘波动率 0，最新量为前 250 根均量的 2 倍。
