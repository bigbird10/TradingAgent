# TradingAgent MVP 需求规格

- 阶段为 Phase 1 需求分析，交付物已确认。本版已纳入核心数据缺失和金融行业评分的确认规则。
- 2026-11-09 完成 AkShare 官方资料核对。文中「必须」来自已确认的 MVP 范围或其可验证的行为要求，「建议 / 待确认」需要评审后才能成为验收基线。

## 1. 项目目标与范围

TradingAgent 服务个人投资研究。用户从中国 A 股中搜索并确认标的，查看最近可得行情与历史走势，生成含定性评价和风险评估的单股报告，并在满足评分条件时提供量化评分。首版保证沪深 A 股主路径，优先保证数据准确性、可追溯性、运行稳定性和数据源可扩展性。北交所的纳入级别由实际数据覆盖评估决定，当前未承诺其完整报告能力。

AkShare 是首版唯一实际接入的外部股票数据渠道。其他数据供应商的并行获取、标准化和回退能力通过模拟数据源验收。首版排除实盘交易、自动下单、账户及投资组合管理、登录、多用户、多租户、角色权限、商业化和分布式部署。

## 2. 用户场景与流程

| 场景 | 用户动作与系统行为 | 用户可见结果 |
| --- | --- | --- |
| 已知证券 | 输入代码、名称或名称关键词，查看候选，确认目标 | 显示证券代码、名称和交易市场。代码保留前导零，同名或近似名称可消歧 |
| 单股研究 | 从候选选择标的，触发分析，查看行情及报告 | 查看最近可得价格及日期、历史走势、四个分析维度、综合评价与风险 |
| 核查结论 | 从指标、评分或风险条目查看证据 | 找到数据来源、对应日期或期间、公式或规则及实际参与计算的输入 |
| 数据异常 | 查询未命中、来源异常、停牌或报告部分可用 | 区分异常原因，展示可用信息与影响范围，给出可重试状态。证据不足时可以只生成部分报告 |

首版搜索验收覆盖代码、名称和关键词。按复杂自然语言条件选股、批量分析以及独立的行业或竞争专题属于后续候选。

## 3. 功能需求

| ID | 优先级 | 必须满足的行为 |

| FR-01 搜索 | 必须 | 按 A 股代码、名称或关键词返回候选，提供代码、名称、交易市场。区分输入无效、未匹配、市场不支持及查询失败。仅在用户确认候选后开始分析。 |
| FR-02 行情 | 必须 | 展示最近可得价格、对应交易日期和历史价格与交易数据。标注复权方式、数据时间和状态。盘中快照与已完成日线在展示及计算中可区分。 |
| FR-03 基本面 | 必须 | 提供营收、净利润、毛利率、净利率、ROE、营收增长率、净利润增长率、资产负债率及经营活动现金流。显示财报期间和可比较趋势，根据证据说明经营优势与潜在问题，输出分数及依据。 |
| FR-04 估值 | 必须，EV/EBITDA 有条件 | 提供 PE、PB、PS，结合已验证的盈利和成长数据评价合理性与估值风险，输出分数及依据。EV/EBITDA 仅在数据可得且口径可靠、指标适用时输出。注明指标时点、计算口径或供应商原始口径。 |
| FR-05 技术面 | 必须 | 使用历史价格和成交量计算 MA20、MA60、MACD、RSI，分析趋势、量价、技术信号及风险，输出分数及依据。说明复权、取样窗口和样本不足状态。信号以研究解释呈现。 |
| FR-06 风险 | 必须，流动性有条件 | 评估财务、估值、股价波动和数据质量风险，成交数据足够时评估流动性风险。每项给出描述、风险等级、依据及不确定性，汇总为综合风险等级。风险未知或证据不足时明确显示该状态。 |
| FR-07 评分 | 必须 | 四个维度各自以 0～100 分表示，按明确规则计算综合分。风险安全得分越高表示风险越低。权重可配置，建议初值为基本面 35%、估值 30%、技术面 15%、风险安全 20%。披露生效权重及未评分原因。综合评分仅在全部必需维度均满足评分条件时生成。 |
| FR-08 报告 | 必须 | 生成第 8 节所定义的结构化单股报告。显示投资价值总结、核心优势、主要风险、需持续关注的指标、正负面因素和综合结论，以及数据和结论的时间边界。 |

### 3.1 指标和评分规则的验收约束

- 所有可确定计算的指标、评分、风险分级阈值和聚合规则均由可测试的确定性逻辑处理。指标规格必须列出字段、计算公式、比较期间、单位、舍入、边界和异常条件。外部来源直接提供的指标标为来源值，附原始指标名及已知口径。
- 对适用且资料齐全的样本，按四维生效权重计算加权综合分。权重合法性、舍入精度、阈值边界和评分规则版本需有明确规定。同一数据快照和相同配置及规则版本应得出相同的数值与风险分级。
- 区分真实零值、字段缺失、尚未披露、来源失败、过期、冲突、样本不足和指标不适用。缺失值或不适用项不得按零参与。明确已评分与未评分指标、有效覆盖和综合结果是否可生成。对盈利为负、分母为零或负数、转盈转亏等情况，保留原始事实并按适用规则解释。
- 评分依据应包含指标贡献、风险触发项或不计分原因。评分解释与报告叙述由 LLM 根据数据和规则结果生成。LLM 可以归纳已有风险和解释证据，生成内容不得填补缺失财务数据、修改分数、风险等级或来源。
- 评分阈值、风险等级聚合及具体指标口径见第 11 节待确认项。报告不要求给出买入、卖出、持有评级或目标价。

### 3.2 核心指标与评分资格（FR-09）

核心指标是当前评分策略要求具备有效证据的指标。非核心指标可补充报告或在已验证规则允许时参与维度评分，其单独缺失不阻止综合评分。分类应按评分策略和维度配置，报告需追溯生效分类及规则版本。以下为普通非金融企业的建议初始分类，具体公式和口径仍需确认。评分分类与功能交付范围分开，非核心的必交指标仍须在数据有效且适用时输出。

| 维度 | 建议初始核心指标 | 建议初始非核心指标 |
| --- | --- | --- |
| 基本面 | 营收、净利润、ROE、营收同比、净利润同比、资产负债率、经营活动现金流 | 毛利率、净利率 |
| 估值 | PE、PB、PS 的有效值或经已验证规则覆盖的异常状态 | EV/EBITDA |
| 技术面 | 有效日线及其计算的 MA20、MA60、MACD、RSI，成交量及其分析所需窗口 | 换手率等补充量价指标 |
| 风险安全 | 财务风险、估值风险和股价波动风险所需的有效输入，以及对核心数据质量的核查结果 | 流动性风险所需的成交额、换手率等输入 |

- 核心数据缺失、过期或质量不达标时，受影响的必需维度不满足评分条件，综合评分不生成。使用有效证据的维度仍可独立分析，符合其规则时可独立评分。受影响的维度也可以展示可核查的事实和可计算结果。
- 禁止用虚构值、默认值或零值替代缺失的核心数据。禁止通过跨维度重分配权重绕过综合评分门槛。指标可由有效数据确定为不适用或处于异常状态，例如实际亏损导致常规 PE 不适用。仅当已验证评分规则明确覆盖该状态时才可参与评分资格判断。
- 报告逐维显示数据完整度，以生效策略的核心指标清单为分母，展示通过质量及时效检查的指标数，并列出缺失字段、过期或质量不达标的指标、数据日期和时效状态。各维度与综合分分别说明未评分原因。没有适用且经过验证的评分策略时，仍列示可用证据与缺口，评分完整度标为无法按策略评估。

### 3.3 金融行业评分（FR-10）

银行、证券、保险等金融行业允许采用专用指标和权重。首版允许输出部分维度报告，并在存在适用且经过验证的维度规则时独立评分。综合评分要求对应行业已有经过验证的专用评分策略，且全部必需维度通过评分资格检查。普通企业规则中的不适用指标应说明原因。仅删除不适用指标并重新归一化权重，不能作为金融行业评分策略或生成综合评分的依据。后续可分别扩展银行、证券和保险的评分策略。

| NFR-07 输出可信 | 校验模型输出是否引用有效证据。模型不可用或输出不合格时清晰标记叙述未生成，已验证的数据和确定性结果仍可查看。 |

**验证覆盖与稳定性（DS-01）**。记录实际 AkShare 版本、上游、标的及板块、测试时间、响应耗时、响应状态、字段缺失率、最早和最新有效记录、行情日期或报告期及披露日期。样本至少覆盖沪深主板、科创板、创业板，并分别选择成熟公司、金融股、亏损或新上市样本。另选北交所样本进行同口径验证。按多个时点重复少量采样，记录异常和数据滞后。关注东财等多个候选接口共享同一上游造成的相关故障。由此判断北交所是否可以开放完整分析、仅开放搜索与可用数据，或首版暂缓。建议当前先以沪深完整分析为验收主线。

## 7. 多数据源扩展与并行获取

| ID | 行为要求 |
| --- | --- |
| DS-02 统一访问 | 数据源与分析分离。各数据源对外提供统一的数据访问语义，按数据类型、市场和口径声明能力。按数据类型配置可用来源及优先级。新增来源应复用现有分析规则。 |
| DS-03 并行与降级 | 同一逻辑请求可并行发往多个适用来源，受请求和整体等待时限约束。来源失败、超时、空值或数据不合格时，可回退到其他合格来源或符合策略的缓存。所有候选均失败时返回明确的不可用状态。 |
| DS-04 标准化 | 对齐证券身份、字段、单位、币种、价格复权、交易日期、统计期间和财报口径。保留原始来源值及转换依据。不可安全转换的数据标明不可比较，避免拼入同一序列或混合分子分母口径。 |
| DS-05 冲突处理 | 先验证身份、时间、口径和有效性，再依确定的规则选用结果。记录主要冲突、候选来源、选用值及理由。重大且无法裁决的冲突标为不可用或部分可用。相同候选数据及配置下，响应先后顺序不能改变选用结论。优先级与可接受差异待确认。 |
| DS-06 首版边界 | AkShare 用于真实数据验收。用至少两个模拟来源证明同一请求并行、来源优先级、超时回退、标准化和冲突处理。模拟数据只用于测试。 |

## 8. 报告信息结构

下表规定报告内容和关联关系，供后续设计使用。

| ID | 内容块 | 必需字段及语义 |
| --- | --- | --- |
| RP-01 | 标的与时间 | 证券代码、名称、交易市场，生成时间、分析基准时间，最近可得行情及交易日期，数据覆盖期间，完整、部分可用或不可用状态。 |
| RP-02 | 分析维度与指标 | 基本面、估值、技术面与风险评估。每项指标有名称、数值或缺失状态、单位、基准日期或期间、口径、来源或输入引用，以及适用性说明。 |
| RP-03 | 风险明细 | 类别、描述、等级、触发条件、证据引用、不确定性及缺失影响。综合风险等级附聚合依据。 |
| RP-04 | 评分明细 | 各维度分数或未评分原因、实际参与的指标和贡献、配置及生效权重、综合分或未评分原因、逐维核心指标有效覆盖、缺失字段、数据日期与时效状态、质量异常及规则版本。风险安全分与风险等级分别显示。 |
| RP-05 | 研究结论 | 投资价值、核心优势、主要风险、正负面因素、跟踪指标、综合结论、适用条件和局限。判断可关联证据，证据不足时保留相应不确定性。 |
| RP-06 | 证据与计算记录 | 客观数据、程序计算、模型推断和主观判断可区分。来源记录包含 AkShare 接口或来源标识、原始供应商、原始字段、获取时间及数据日期或披露日。计算结果关联输入、公式或规则版本与参数。未知元数据显式标记。 |

## 9. 可执行的验收场景

固定输入和模拟来源用于可重复测试。联网验收使用真实 AkShare 响应，记录环境、版本、时间、样本和结果。涉及待确认阈值的用例须在规则确认后冻结预期值。以下为验收规格，当前阶段未运行产品测试。

| ID | 对应需求 | 输入与操作 | 通过条件 |
| --- | --- | --- | --- |
| AT-01 | FR-01、AS-01 | 固定名录含深市 `000001` 和多条含「银行」的名称。分别搜索代码、完整名称和关键词，从候选中选择一只股票。 | 保留前导零，候选含市场，关键词返回对应匹配，选择前无分析，选择后报告使用同一证券。 |
| AT-02 | FR-01、NFR-02 | 分别输入非法代码、格式有效但名录中不存在的代码，模拟名录超时，再输入暂未开放市场的标的。 | 四种结果可区分。超时可重试且不显示为无匹配。 |
| AT-03 | FR-02 至 FR-08、DS-01 | 个人环境启动，对已确认的沪深板块代表样本用真实 AkShare 拉取名录、历史行情、财务和估值。对成熟非金融沪深标的各生成一份报告。 | 四维均能输出真实分析，报告包含定性、各维度与综合评分、风险等级和可复核来源。对北交所及特殊标的记录实际覆盖和缺口。 |
| AT-04 | FR-03、AS-04 | 使用同口径累计营收上期 80、本期 100，本期总资产 200、负债 120。再加入同一报告期在分析基准时间之后才披露的更正记录。 | 营收同比为 25%，资产负债率为 60%，未披露更正不参与计算。另用固定样本核对其余财务指标、趋势、期间和证据。 |
| AT-05 | FR-04、AS-03 | 固定同口径市值为 1000、TTM 归母净利润为 50、归母净资产为 250、TTM 营收为 500，另给负利润及缺少 EBITDA 的样本。 | 若采用第 11 节建议口径，预期 PE 20、PB 4、PS 2。亏损 PE 不能作为正常低估信号，EV/EBITDA 缺口可见。 |
| AT-06 | FR-05、FR-06、AS-02、AS-03 | 使用 1 至 60 的连续有效收盘价测试均线，再用足够长的固定量价序列及独立参考结果核验 MACD、RSI、波动率、量价和流动性规则。插入休市日、停牌记录并缩短样本。 | 第 60 条 MA20 为 50.5、MA60 为 30.5。其余指标在已确认精度内匹配参考结果。停牌、休市不填行情，历史不足标注对应指标。 |
| AT-07 | FR-06、FR-07、RP-04 | 将四维分数设为 80、70、60、90，用建议权重和另一组合法配置各运行一次。再注入缺失、不适用、非法权重与风险阈值边界。 | 建议权重下综合分为 76。修改权重后按配置重算，非法权重可识别。缺失不计为零，风险安全分、风险等级及触发依据符合确认规则。 |
| AT-08 | FR-06、FR-08、AS-02、AS-04 | 模拟未披露财报、行情接口超时、停牌、普通休市、缺少停牌证据的交易日空档及过期缓存。 | 逐项区分原因，显示最后有效日期或财报期及实际覆盖。可以继续输出有证据的部分，不用缓存获取时间冒充行情时间。 |
| AT-09 | DS-02 至 DS-06 | 模拟 A、B 对同一请求均已开始，再放行结果。让高优先级 A 超时，B 返回以万元计量的数据。另设 A 与 B 有可比较冲突、不可比较复权和响应顺序互换的样本。 | 证实请求重叠、按期回退、单位转换和来源保留。响应先后不决定选值，不可比较结果不合并，冲突可追溯。全失败时状态明确。 |
| AT-10 | NFR-01 至 NFR-07、RP-01 至 RP-06 | 在干净的受支持个人环境按说明启动，使用固定快照重复计算。模拟 LLM 不可用和模型返回无证据指标或擅改分数。 | 可安装运行，日志定位请求及失败。确定性输出可复现，报告区分四类信息。模型异常不污染数据与评分，保留可查看的确定性结果。 |
| AT-11 | FR-09、RP-02、RP-04 | 用可完整评分的普通企业固定样本，分别移除、过期化或破坏一项核心输入，再仅移除一项非核心输入。通过合法配置变更将该非核心项设为核心后重跑。 | 核心输入异常时无综合分，其他有效维度可独立分析和评分。报告列出数据完整度、缺失或无效项、时效和未评分原因。仅缺非核心项时不单独阻止综合分。分类变更后按生效规则判定，无虚构值或默认值参与。 |
| AT-12 | FR-10、RP-04 | 分别以银行、证券和保险固定样本运行，保留有效技术数据，设通用财务指标不适用且无经过验证的行业策略。尝试删去不适用项并重新归一化。 | 部分报告仍展示有效分析和不适用原因，综合分不生成且标明行业策略未验证。删除指标或重新归一化无法绕过门槛。 |

## 11. 待确认事项与建议决策

| ID | 待确认事项 | 建议及其影响 |
| --- | --- | --- |
| Q-01 | 北交所与数据覆盖门槛 | 以 DS-01 的样本验证作为纳入依据。建议先明确沪深完整分析承诺。若北交所只能可靠获取名录和行情，待确认是开放有限覆盖并标明缺口，还是暂缓纳入。 |
| Q-02 | 行情、技术指标与历史窗口 | 建议以最近已完成交易日为主，展示实际未复权价格，以口径一致的前复权日线计算技术指标并固定当次输入快照。对收益率所用非正价格标记不可用。建议评估取最近 250 个有效交易日、MACD 12/26/9、RSI 14，并明确 EMA 初始化、RSI 平滑、波动率与成交量窗口及最少样本。 |
| Q-03 | 财报及估值口径 | 建议优先使用合并报表，趋势展示最近三个已披露年度与最新累计期的同口径同比。明确净利润与归母净利润、平均权益 ROE 与供应商 ROE 的选择。建议以同一市值基准的 PE TTM、最近已披露归母净资产 PB、PS TTM 为目标口径。来源口径无法验证时标示原始指标和限制。 |
| Q-04 | 金融行业及异常分母 | 部分报告和综合评分门槛已按 FR-10 确认。具体行业指标、权重和验证标准留待行业评分策略定义。建议将亏损、负权益及利润由负转正分别定义为有明确解释的状态，确认各状态如何影响普通企业评分资格。 |
| Q-05 | 初始指标分类、评分档位与风险聚合 | 缺失处理门槛已按 FR-09 确认。待确认第 3.2 节建议分类、各维度评分阈值、非核心指标的计分方式、风险等级与安全分映射，以及关键高风险能否提升综合风险等级。 |
| Q-06 | 新鲜度、回退与冲突 | 建议按数据类别及交易日或披露期定义过期界限。已验证且可比较的候选按配置优先级选择，超出容差的冲突保留证据并提示，重大未决冲突停止相关评分。需确认容差、哪些过期数据可用于计算，以及本地运行的超时预算。 |
| Q-07 | 交互、运行环境与模型服务 | 建议单人本地运行，报告优先可直接阅读并核查。需确认第一版是否必须提供浏览器界面、首要支持的操作系统、模型服务可用条件和可传给外部模型的数据边界。 |
