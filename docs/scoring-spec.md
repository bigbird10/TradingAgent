# TradingAgent 评分与风险规则规范

TA-10 · 候选 `scoring-spec-0.1.0` · 指标口径 `indicator-spec-1.0.0`。适用于沪深普通非金融企业的规则评审。依据 [需求 FR-06、FR-07、FR-09、FR-10](requirements.md) 和 [架构 Q-04、Q-05](architecture.md#10-决策记录与阶段交接)。本文区分已确认的业务门槛、待评审的政策设计和仅用于测试的输入。[候选配置](../tests/fixtures/scoring/policy-0.1.0.json) 位于测试目录，生产启用为 false。

## 1. 资格、证据与部分结果

以冻结的证券、市场、行业及其证据、分析时点、指标规范版本、来源快照和生效策略为输入。每项输入保存指标 ID、值或状态、单位、观察日或期间、可用时点、业务时效状态、质量和口径、冲突及证据 ID。来源值和计算值分别保存。历史估值要求与该收盘时点匹配的财报版本、股本、复权与币种证据。缓存 TTL 仅控制获取，业务时效须依据市场交易日和应披露期间判定。缺少核准时效规则或无法判定时效的核心输入不可计分。

| 维度 | 候选核心清单 | 可选报告指标 |
| --- | --- | --- |
| 基本面 | 合并营业收入、合并净利润、报告期 ROE、营收同比、归母净利润同比、资产负债率、经营活动现金流 | 毛利率、净利率 |
| 估值 | 经证据验证并按规范重算的 PE TTM、PB、PS TTM | 条件 EV/EBITDA、静态 PE |
| 技术面 | 合格的完成前复权日线、MA20、MA60、DIF、DEA、MACD 柱、Wilder RSI14、均量及量比 | 成交额及其均值、换手率 |
| 风险安全 | 财务、估值和股价波动三个风险项的合格输入及结果，核心数据质量检查 | 具备成交额证据时的流动性风险 |

- **逐维判定**。合格输入必须适用、证据完整、口径匹配、状态有效且业务时效合格。记录合格核心项数及总数、缺项及原因、数据日期、规则版本和证据。策略未验证或不适用时，正式报告的策略评分覆盖率为无法评估，同时列示已取得的证据与缺口。正常可观测零和有效零分按其规则处理。
- **异常分开**。缺失、未披露、超时、过期、冲突、样本不足、适用性未知和不适用均保留具体原因。亏损 PE、负权益 PB、非正基期增长率保留原事实和不可计算状态。此候选没有给这些异常设置替代分，须另行验证并批准明确的适用规则。禁止缺失填零、用供应商原值替代重算值、跨维度重分配权重。
- **部分分析**。有证据的指标和已验证风险项独立展示。维度评分仅在该维度有适用且批准的规则、全部核心输入合格并得出有效分数时生成。综合分要求四个维度全部合格。行业未证实或缺乏已验证的银行、证券、保险专用策略时，综合分留空。合法行业专用策略须独立核准指标、权重和缺失处理。
- **当前生产边界**。TA-08 的沪深样本缺少数值与正式披露版本的绑定，以及历史股本、适用时间和股类覆盖证据。供应商估值可单列参考。相关基本面、严格 PIT 重算估值及其派生风险不得进入正式评分。TA-09 合格行情可用于研究解释，其得分仍须通过已批准策略的门槛。[TA-08 缺口记录](validation/ta08-financial-sources.md#待补的生产证据)

## 2. 确定性评分与输出

初始百分比权重为基本面 35、估值 30、技术面 15、风险安全 20。候选配置允许四项各为 1～99 的整数百分比，合计须精确为 100。键须完整且唯一，拒绝未知键、布尔值、缺项、负数、小数和非有限值。任何维度不合格时，综合分为空，列出失败门槛。各维度分数为有限值且在 0～100，零分只用于有效输入触发的结果。

`综合分 = Σ(维度原始分 × 生效百分比权重 / 100)`。中间值按十进制至少 34 位工作精度或精确有理数计算。展示采用半偶舍入到两位小数，中间贡献保留原精度。示例四维为 80、70、60、90，贡献分别为 28、21、9、18，合计 76。等权时合计 75。保存输入、状态、贡献、权重、规则、版本及生效配置摘要，叙述只能引用确定性输出。

可选报告项独立缺失不改变常规维度权重或得分。将可选项提升为核心须产生新策略版本并重新核准。流动性风险在达到证据条件时可按第 3 节影响风险聚合。部分报告明确披露风险覆盖范围，避免直接比较覆盖不同的两个综合风险等级。

## 3. 候选风险聚合

| 风险项 | 所需证据与规则方向 |
| --- | --- |
| 财务 | 已披露且同口径的总资产、总负债、利润及经营现金流。披露杠杆、亏损或现金流为负等事实。拟在可比企业内检验杠杆较高对应更高风险的分层。负利润、负现金流和账面资不抵债各自保留证据与期间。 |
| 估值 | 同一发行人口径与行情时点的有效 PE TTM、PB、PS TTM。拟检验相对估值偏高的风险暴露，结合盈利和成长性复核。亏损 PE 按不适用处理，不能被当成低估或低风险。 |
| 股价波动 | 规范定义的前复权年化实现波动率，窗口、交易日、样本数及缺口合格。相同口径下波动越大，已观测价格变动越大。分档需实测，结果不等同最大损失、未来波动或违约概率。 |
| 数据质量 | 输出覆盖率、缺口、时效和冲突。质量不足使依赖该输入的风险项不可判定，并阻止正式风险聚合。 |
| 流动性（可选） | 规范定义的同口径成交额及其窗口，交易状态和缺口有据。拟检验较低成交额对应更高流动性风险，结合交易规模及其他可验证证据解释。成交额单独不能证明实际冲击成本。 |

候选有序等级为低、中、高。财务、估值、波动三项均已评级且核心数据质量合格时，取三项的最高等级。有合格的可选流动性等级时，它可以提高综合等级。其缺失记录为可选证据缺口。核心项不齐时，仅展示已验证风险项，综合风险等级与安全得分留空，即便某项已知为高风险。各风险条目附触发指标、规则 ID 和版本、证据、依据、不确定性。安全得分候选映射为低 100、中 50、高 0，表示离散顺序，未经校准。最高等级聚合的理由是保留单项高风险信号，其误报敏感性及可选项带来的覆盖差异需验证。

## 4. 阈值依据及验证计划

**已有依据的边界**。PE、PB、PS 的非正分母处理沿用已确认指标规范。资产为正且合并负债等于或大于资产总额时，可分别报告合并账面总权益为零或为负的会计事实。其含义不能外推到归母权益口径或违约概率。行业差异及盈利质量限制估值倍数的可比性，因此无全市场固定倍数档位。 [财政部《企业会计准则——基本准则》第二十六及二十八条](https://www.mof.gov.cn/zcsjtsgb/gztsgb/201407/t20140723_3578373.htm) · [证监会江苏监管局基本面分析材料](https://www.csrc.gov.cn/jiangsu/c105409/c1284129/content.shtml)

**可验证的候选分层**。拟以冻结、同期、同口径的可比非金融样本估计经验分位，在同一指标与可比组中研究下四分位、中间区间和上四分位。候选边界采用最近秩分位，排序后取从 1 开始的第 `ceil(p × n)` 项。以原始值划分低于下界、下界至上界（含下界）、达到或超过上界三档。对值越高风险越高的指标对应低、中、高风险。对值越低风险越高的指标对应高、中、低风险。并列阈值或覆盖不足时不分级。四分位设计只是试验分组，未证明可作为正式投资阈值。本配置的 `calibration` 为 null，无正式可执行阈值。

流动性研究会将价格变动与成交额组合为粗略的冲击代理。本期仅冻结成交额指标，待实证决定流动性是否参与风险聚合。 [Amihud 流动性研究](https://www.cis.upenn.edu/~mkearns/finread/amihud.pdf)

研究阶段可在可比组内比较基本面盈利、增长、经营现金流相对营收和杠杆，估值三项倍数，以及技术趋势差相对 MA60 的强弱。研究用维度分可采用有向中秩百分位并比较等权与替代组合。此方案需要验证行业可比性、样本数量、数值方向和估值与风险重复计入的影响。MA、MACD、RSI 仅提供研究信号，阈值方案不产生交易指令。

| 验证层 | 通过条件与当前状态 |
| --- | --- |
| 计算正确性 | 固定输入和独立断言覆盖权重、聚合、分档方向和等号、真实零、缺失和异常、证据资格及行业边界。测试用阈值只检验规则行为。 |
| 投资解释与实证 | 先冻结带实际披露及修订时点的可比样本、样本期、覆盖和最少样本、观察目标及对照，再做时间顺序的样本外验证。评估不同市场环境的稳定性、误报漏报、缺失覆盖、候选权重及分档敏感性。记录样本、计算版本、证据和人工复核结论。当前缺 TA-08 的关键 PIT 数据，尚无支持正式使用的结果。 |
| 正式启用 | 需有经过验证的阈值、行业适用性、正式时效标准、可追溯样本外证据和明确评审批准，再发布版本化配置。任一条件不足时禁止启用。仅更改开关或批准标志不能弥补缺失的校准证据。 |

校准配置待验证后填写。每条正式规则须绑定指标 ID、数据与指标版本、适用样本组及其摘要、单位、比较方向、阈值和等号归属、最少覆盖、有效期及验证记录。配置缺项、边界次序无效、口径不符或样本组缺失时，该规则不可执行。

可比样本的固定方式和样本外验证是政策验收证据，无需扩展本期报告功能。样本内多次调参会抬高样本外失效风险，验证结果须保留尝试和选择记录。 [回测过拟合研究](https://papers.ssrn.com/sol3/Delivery.cfm/SSRN_ID2423465_code434076.pdf?abstractid=2308659)

## 5. 评审与交接

候选配置和黄金用例只验证规则可执行性。尚需确认初始核心清单、整数权重范围、异常估值的继续禁用规则、最高等级聚合、可选流动性是否允许抬升，以及 100/50/0 安全分映射。正式阈值及风险聚合须取得投资解释和实证审核依据后批准。TA-10 的正式验收保持待验证。TA-11 仍同时依赖 TA-08、TA-09、TA-10，评分引擎实现由 TA-11 交付。
