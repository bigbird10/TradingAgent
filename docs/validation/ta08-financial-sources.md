### 指标使用边界

| 用途 | 当前范围 |
| --- | --- |
| 当前报告可用 | 有日期的未复权收盘、财报报告期和公告线索可作背景。供应商总市值、PE TTM、PB、PS 带日期、单位和来源标为供应商原值，可作参考。 |
| 已离线验证的计算 | AT-04 的基本面金额、比率、同比和报告期 ROE，以及 AT-05 的市值与 PE、PB、PS 重算、亏损和缺证分支，已使用固定且具备完整证据的输入验证。两只在线样本暂不能据此生成正式基本面或重算估值。 |
| 暂不可进入正式评分 | 未证实版本的三表数值与派生指标、缺少股本或披露证据的严格 PIT 估值、口径未核验的供应商原值均不可计分。EV/EBITDA 在已测估值接口中缺失，待核验构成项。金融股缺少经确认的适用映射或评分规则时保留相应缺口。任一必需维度不合格时保持综合分不可用。 |

### Provider 内可评估的补证方案

- **正式披露与更正**。保留 AkShare 三表作发现入口，结合巨潮公告接口和交易所正式披露附件核对初版与更正版本。TA-01 已取得巨潮更正公告线索。后续应以附件为证据，验证数值、单位、期间、披露精度与版本关系，再按标准字段冻结。限制为已验证的版本，旧快照保留原状。 [TA-01 公告实测](akshare-feasibility.md#财报时点实证)
- **股本与估值**。评估 AkShare 的巨潮股本变动接口 `stock_share_change_cninfo`。上游实现区分公告日期和变动日期，并暴露总股本及部分股类字段。沪深各一只样本已实测。后续仍需以正式股本变动公告核实连续覆盖、生效区间和股类，再与未复权收盘、同口径市值及分母逐项比对。[PV-01 时点证据补验](ta08-pv01-pit-evidence.md) [AkShare 股本变动接口源码](https://github.com/akfamily/akshare/blob/main/akshare/stock/stock_share_changes_cninfo.py)
- **接入边界**。补证适配仍通过现有 Provider 能力和标准化证据契约，按数据组验证和配置。对未映射、超时、证据冲突或缺失保持现有降级。该方案仅评估补证路径，现阶段未启用额外数据供应商。
