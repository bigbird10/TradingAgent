# TA-01 · AkShare 真实接口可行性验证

验证日期为 2026-11-10，时区 Asia/Shanghai。基线为 [需求 DS-01](../requirements.md#6-akshare-能力与数据缺口)、[架构第 5 节](../architecture.md#5-数据工具并行查询和选择规则)和 [TA-01](../tasks.md#ta-01--akshare-真实接口可行性验证)。

## 结论与 M0 边界

- **验证交付已完成。** 三轮共 101 次真实调用，97 次返回非空，另有 1 次上游超时、1 次探测截止和 2 次分类公告空结果。首轮的深市名录超时后，两轮直连复测均成功。本次结果覆盖同一晚间的三个时点，尚无跨交易时段的稳定性或更新延迟数据。
- **沪深当前单股主路径具备数据可行性。** 沪深两个成熟非金融样本取齐了当期价格、前复权日线、三表、主要指标、正式公告线索和 PE/PB/PS。创业板、科创板及特殊样本的差异可明确识别。M0 可进入最小闭环，正式财务指标和评分仍受 TA-07、TA-10 的规范关卡约束。
- **北交所建议开放搜索和基础行情。** 两个现行代码均通过名录及有日期的日线验证。四维分析只对艾融软件试取，仍需更多同口径样本及报告验证，保持未开放。
- **财报历史版本有实测缺口。** 东财会把更正后值与原披露日放在同一条记录。历史时点无法证明某个数值可用时，阻塞该输入及其评分。建议通过 AkShare 公告接口关联正式披露和更正，保守过滤只有日期的记录，并冻结本次快照。既定 MVP 提供用户触发的当前分析和已有快照复算。若后续需要重建历史时点数据，须另行验证原始版本覆盖。

实测为 macOS 14.1.1 x86_64、Python 3.12.3、AkShare 1.20.36、pandas 3.1.1。使用独立临时环境，联网通道经沙箱外批准。默认沙箱下 PyPI 和行情域名无法解析。环境依赖见 [实测版本清单](ta01-environment.txt)。固定的是本次实测版本，后续升级须重新跑关键接口。ARM64 及其他操作系统未覆盖。

在联网环境用 Python 3.12 复跑。输出路径必须是新文件。省略 `--as-of` 时使用当前上海时间。

```sh
python3.12 -m venv /tmp/tradingagent-akshare-probe
/tmp/tradingagent-akshare-probe/bin/python -m pip install -r docs/validation/ta01-environment.txt
/tmp/tradingagent-akshare-probe/bin/python scripts/probe_akshare.py --output /tmp/ta01-akshare.json
/tmp/tradingagent-akshare-probe/bin/python scripts/probe_akshare.py \
  --only list.SZ --only revision.actual. --only revision.statement --output /tmp/ta01-repeat.json
```

[探测脚本](../../scripts/probe_akshare.py)限定最多两个并行调用，默认每次最多 35 秒，子进程超时后被回收。本次探测不在外层自动重试，以保留各轮失败。退出 0 表示所选接口均返回非空，字段、口径、日期与能力仍需检查。退出 1 时仍写入观测证据。证据仅保留公开样本的白名单字段、列名、日期范围和缺失计数，不保存整张行情表、凭据或原始错误正文。日期范围反映返回数据，不代表上游保证的历史起点。财报和估值接口返回取数时的历史表，`--as-of` 约束日线窗口，不能用于还原历史数据版本。

首轮为探测脚本的初始格式。首轮 `fallback.list` 的来源标签应读作 **SSE/SZSE/BSE**，后两轮脚本使用正确的聚合来源标识。新版证据补充上海业务日期、超过基准日的行数和更正样本的指定报告期。日期超界计数仅按日期字段统计，财报可用性需另核披露与更正日期。

### 财报时点实证

- 688981 的三表最新为 2026-06-30。公司在 10-31 预告 11-12 收盘后披露三季度业绩，故在本次 11-10 基准时点应标为三季报尚未披露，并保留最近已披露半年报。 [中芯国际公告](https://big5.sse.com.cn/site/cht/www.sse.com.cn/disclosure/listedinfo/announcement/c/new/2026-10-31/688981_20261031_LO5M.pdf)
- 600368 的 2024 年报仅返回一条。东财记录的原披露日为 2025-03-29，更新日为 2026-04-18。营业收入 1,562,610,519.04 元与 2025-12-20 更正后值相符，原值为 1,823,013,143.58 元。以原披露日赋予更正后数值会引入未来信息。以更新日替代正式更正日也不能准确还原披露时间。 [五洲交通 2024 年报更正公告](https://static.cninfo.com.cn/finalpage/2025-12-20/1224888631.PDF)
- 同一标的 2025 三季报仅返回一条，原披露日 2025-10-28，更新日 2026-10-31。更正公告在巨潮和东财显示为 2026-04-04，监管记录为 2026-04-03 披露。本次保留日期精度，不从这些字段反推日内时点或历史版本。限定更正分类的一组探测为空，后续使用真实更正日期和巨潮关键词才取得公告。 [公司更正公告](https://static.cninfo.com.cn/finalpage/2026-04-04/1225080163.PDF) · [广西证监局记录](https://www.csrc.gov.cn/guangxi/c104662/c7639425/content.shtml)
- TA-07 应用这些样例锁定口径。当前报告只纳入能证明在分析基准前可用的值。只有日精度时可采用次日生效的保守候选规则，有更正迹象且无法对齐版本则标为不可用。原始版本缺口通过正式披露附件或既有快照补证，补证失败时输出部分结果并阻断相关综合分。

## 初始运行参数建议

下表用于后续实现评审和测试，未作为正式业务配置。样本集中在同一晚间，不能据此承诺限流阈值或全天更新延迟。

| 项目 | 试验建议与依据 |
| --- | --- |
| 并发与重试 | 全局最多 2 个，东财共享同一配额；同一标的的三表可顺序或在剩余容量内并行。瞬态网络错误在剩余预算内最多重试 1 次并退避；字段或口径错误直接归类。本次没有观测到明确 429。 |
| 截止 | 快速行情、估值、日历可从单次 15 秒试起，直连名录 20 秒，分页三表 35 秒，整组取数暂以 90 秒预算验证。成功日线约 1–2 秒，三表约 2–12 秒，深市名录曾在约 13 秒时失败，深市快照在 35 秒回收。 |
| 名录、日历与停牌 | 名录缓存可从 24 小时试起，确认上市和退市生效状态。日历缓存可从 7 天试起，必须覆盖请求日期，年末跨界需要刷新验证。停牌证据按交易日和状态区间判定。 |
| 日线和估值 | 收盘后首轮可从 16:00 上海时间试采，并要求数据日期与最近有效交易日相符。等待上游更新时可展示最近已知值和状态，核心时效未满足则阻止评分。盘后和开盘前需要专门复测。 |
| 财务与披露 | 按正式披露、报告期、版本和是否尚未披露判定。正常时缓存可从 24 小时试起，披露窗口可缩短至 2 小时。重新取数不能改变原始披露时间。 |
| 冲突 | 价格比较先对齐日期、币种和复权，容差以已核实的显示精度推导。600519 同日三源收盘均为 1,444.99，但东财 24,801 手、新浪 2,480,122 股，腾讯转换后为 2,480,100 股。成交量保留原值并标注换算或舍入，不把三条记录平均。未经验证的跨来源容差保持禁用。 |
