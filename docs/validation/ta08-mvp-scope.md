# TA-08 验收边界与补验方案

产品决策将 MVP 的生产验收聚焦当前时点的沪深 A 股研究。建议将 TA-08 尚待完成的验收拆成 TA-08-A 和 TA-08-B，原编号及验收证据继续作为追溯入口。拆分方案及其依赖映射供评审。

## 1. 验收边界

| 层次及单元 | 通过条件 |
| --- | --- |
| L1 / TA-08-A · 当前时点财务与估值 | 用真实沪深成熟非金融样本分别复算基本面与 PE TTM、PB、PS TTM。核验正式披露、版本及修订、实际使用的各期财务字段、价格和估值适用股本的同口径证据。A/H、库存股、股本变动、冲突与缺证须按证据产出或降级。供应商原值单列。 |
| L2 · 历史趋势 | 有证据的历史行情继续用于趋势。财务趋势保存实际报告版本，明确标注当前可得修订数据的观察视角。只有具备历史可用性证据时才描述为当时可见。 |
| L3 / TA-08-B · 严格历史 PIT | 后续验证多个历史截面的原版与更正链、股本有效区间及当时可用性、行情和估值输入的历史复原，包含股本变动前后和盘后披露对照。历史回测另列后续能力。 |

L1 沿用已确认指标规则。财报可用于当前基本面的时间，取决于分析基准时点。按收盘日期标记的估值另以该收盘时点为输入截止，盘后披露的财务数据可进入当晚基本面，估值待后续合格行情。股本也须同时证明在估值时点已生效且所用信息当时已可获得。只验证当前一组时点和为计算所需的历史财报期，无需重建任意历史收盘日的当时视图。保留 [指标规范](../indicator-spec.md#估值计算) 及既有时点回归用例。

## 2. 既有证据及当前缺口

- 五洲交通的 2024 年报原版、更正公告和两个生效交易日可继续作为版本边界证据，并验证 L1 选择当前适用版本时的防泄漏规则。它同时是 L3 后续回归的样本。
- 贵州茅台和美的集团三季报已证明营业收入与营业总收入需要分别映射，部分金额和报告单位已对齐。正式报告字段的位置、原始单位、币种、累计或单期、合并范围、公告标识、披露精度和版本需与本地快照逐字段绑定。需补齐当前指标依赖的上年同期、期初权益、年度及 TTM 组成期，核对最新适用披露和更正，避免只对照三季报单点。
- 贵州茅台股本事件、正式半年报及未复权收盘可作为当前单股类复算的种子证据。仍需核验目标收盘适用股数，证明相关股本事件覆盖，并核对库存股处理、发行人范围及财务分母。美的集团精确复现东财市值的等式保留为口径差异证据。  [PV-01 实测](ta08-pv01-pit-evidence.md)

对美的集团及其他多股类发行人，按下列口径分别核验。

| 口径 | 必需证据 |
| --- | --- |
| A 股市值 | 估值适用 A 股股数、未复权 A 股收盘、人民币、市场与报价时点。 |
| H 股市值 | 估值适用 H 股股数、未复权 H 股收盘、港币、市场与报价时点。 |
| 公司整体股权市值 | 所有相关股类分别按各自价格计价，并按可验证、与估值时点一致的汇率折算后合计。需要验证停休市时点对齐、库存股与其他股本调整，以及整体市值与合并分母的发行人及权益范围。 |

每类股本分别记录法律或登记生效时间、披露时间及其精度和可用边界，保留已发行股数、库存股和估值采用股数的关系。库存股扣减须有可追溯的口径依据，遇到回购、注销、行权或变动冲突时先核实适用区间。美的集团的港交所披露在目标 A 股收盘后发布，不能用于该收盘的严格历史 PIT 估值。A 股价格乘 A/H 总股本的供应商复现值只能作为来源观察，不能用于已验证的公司整体倍数。

## 3. 启用与降级

| 类别 | 当前生产规则 |
| --- | --- |
| 普通单一 A 股类发行人 | 满足 TA-08-A 证据门槛后，按指标逐项启用正式估值。仅凭名录类别不能启用。 |
| A/H 或其他多股类发行人 | 有完整股类价格、股数、时点、币种及权益范围证据时，可计算对应口径。只有 A 股证据时可展示 A 股范围的市值，不能搭配全公司财务分母生成整体倍数。未核实的供应商值单列并排除评分。 |
| 回购、库存股、行权、拆并股、停牌或报价陈旧 | 仅在股本适用区间、计价基准和时效可证明时计算。缺口、冲突或不同口径时保留已核验事实和降级原因。 |
| 亏损、非正分母或金融股 | 逐指标标注缺失或不适用，沿用已验证分母与行业规则。行业专用评分资格独立判定。 |

L3 独有的发布要求是为所宣称的历史范围证明连续覆盖，并重建任意受支持截面的可见版本和双时间股本。L1 仍须验证目标收盘与实际计算所用历史财务期的证据。两者都排除未来信息、未经验证的版本和错误股类口径。

## 4. 最小补验顺序

1. **冻结三个场景**。选贵州茅台及一只可核实单一 A 股类的成熟深市非金融样本作为正例，美的集团作为 A/H 降级反例。每只正例先固定一个当前分析时点和对应已完成收盘。五洲交通沿用已核验的更正回归，暂不扩大历史股票或时点范围。
2. **绑定必要财务字段**。核验正例最新正式报告、相关修订和计算所需的最少比较期。固定原文件、页码或表格、原始字段值与单位、标准化值、披露和可用时间。发现缺证时记录受影响指标及可验证的替代来源。
3. **核验分子**。用未复权收盘及正式股本记录证明目标收盘适用股数、库存股处理及股类范围。验证美的集团样例因时点和计价范围降级。
4. **离线复算后验证真实路径**。用独立预期复核基本面和三个倍数，覆盖变动、盘后披露、错误单位、A/H 范围、冲突和来源原值展示。用真实沪深样本通过数据接入、计算、快照和报告，保存版本、时点、失败及证据。只有满足上述证据时才建议提交 TA-08-A 正式验收。

## 5. 依赖和门禁

TA-11 只能消费已验收的 L1 计算结果。逐指标核对证券身份、分析和估值时点、版本和证据引用、单位、发行人及股类范围、业务时效、适用性和冲突状态。现有供应商原值或未核实的派生结果排除计分。PV-02 阈值样本外验证与 PV-03 聚合样本外验证及人工评审仍是独立阻塞，所需时点数据证据按验证方案取得。TA-11 的生产依赖仍待正式验收，TA-13 继续等待 TA-11。后续增强 TA-08-B 不列入 MVP 发布门禁。

更新后的 AT-03 与 EV-07 发布验收聚焦 L1 真实端到端证据。EV-04 保留 AT-04、AT-05 黄金用例及现有历史防泄漏回归，补充股类、库存股及冲突场景。EV-06 补充正例与按证据降级的报告快照验证。M1 离线门禁、真实模型验收和完整 MVP 发布证据继续分别记录。既有评测清单及历史运行记录按原版本归档，新增断言待补验阶段实施。 [评测门禁](../evaluation-metrics.md) · [任务记录](../tasks.md#5-ta-08-范围评审补充记录)
