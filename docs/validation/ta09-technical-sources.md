# TA-09 技术指标与交易状态验收

2026-11-10 · AkShare 1.20.36 · 指标规范 `indicator-spec-1.0.0`。

## 计算与快照

- 技术模块只处理标准化日线。报告中的基础行情仍展示未复权价格，技术输入单独冻结为前复权。AkShare 日期范围按有效根数目标推导，默认留存最近 250 根。样本不足且历史可扩展时最多补查一次。配置 `TRADING_AGENT_VOLATILITY_WINDOW`、`TRADING_AGENT_LIQUIDITY_WINDOW` 可提高所需根数。
- MA20、MA60 使用 SMA，至少分别需要 20、60 根。MACD 使用 SMA 初始化的 EMA(12,26,9)，DIF 最少 26 根，DEA 和柱最少 34 根，柱为两倍 DIF 与 DEA 之差。Wilder RSI14 最少 15 根。波动率默认取 20 个简单收益的样本标准差并以 252 年化。均量、均额默认 20 根，量比需要 21 根且基线不含当期。趋势描述 MA20 与 MA60 的相对位置。
- 快照冻结实际请求、接收的行情和状态来源、选择与失败证据、保留的交易日、缺口日期和规则参数。报告保留样本数、数据截止日期、复权、指标状态和证据引用。数值保留计算精度，界面显示使用两位小数的半偶舍入。
- 有正证据的休市和停牌不计入样本。未解释的交易日缺口或缺收盘使窗口重新预热。行情源冲突或非有限价格阻止对应计算，缺失或异常量额只影响依赖这些字段的指标。业务截止日期与缓存到期时间分别处理。
- 停复牌接口只查询当前计划交易日和最近一个缺行情的历史计划交易日。空响应、无匹配、无明确日期区间或证据不充分时保留未知。历史上未核验的缺口按缺失处理。日历覆盖之外不能认定休市。当天完成数据尚未核验，盘前和盘中显示未收盘，收盘后保留未知。 [AkShare 停复牌接口说明](https://github.com/akfamily/akshare/blob/main/docs/data/stock/stock_issue.md#停复牌信息)
